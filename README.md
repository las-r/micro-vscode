# micro-vscode
A VSCode extension adding syntax highlighting for [micro](https://github.com/las-r/micro).

## Installation
1. Download the latest `.vsix` file from the [Releases](https://github.com/las-r/micro-vscode/releases) page.
2. In VSCode, open the Extensions panel.
3. Click the `...` menu at the top right and choose `Install from VSIX...`.
4. Select the downloaded file.
